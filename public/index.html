  • Jakob's Agent Skills

    A set of agent skills I've built for my own workflow and refined project by project. Most of what I do with AI runs through them. If one fits how you work, take it and adapt it.

    To install a skill, download the file and tell your AI: "Install the skill I just downloaded." Then start it by typing its name, for example /workaround (in Codex: $workaround).

    • /workaround

      Download

      AI agents sometimes keep running into the same wall instead of looking for a way around it. This skill finds another way to your goal when something outside your control blocks the direct one, like a failing tool or a missing feature. It checks that the new route really works and tells you what it cost. It stops at permission and security checks instead of getting around them, and asks before system-wide changes like a global install or before deleting something that can't be restored. Start it with /workaround.

    • /fresh

      Download

      The longer a session runs, the more context piles up, and the slower, costlier and less precise the agent gets. This skill carries your work over to a fresh session at a natural break, like a large context, a long pause, a new topic or a finished task. It writes a handoff file, names the recommended model and effort for the next session and offers to start it. The handoff file builds on Matt Pocock's fantastic /handoff, which writes the file when you call it. /fresh also decides when it is time, and an optional Claude Code hook nudges it when the context gets large or after a long pause. The hook is only set up if you ask for it. Runs on its own when the hook is set up (Claude Code), or start it with /fresh.

  • Student Handbook

    A guide for animation students at the Salzburg University of Applied Sciences (FH Salzburg) in Austria. It explains the equipment and software the school gives students access to. It also lists student events, film festivals, job offers and discounts.

    studentbenefits.page

  • Students on the Loose (incl. Inca 3D & Pict 2D)

    Small pixel students walk across the page and react to objects you place there. You create and place the objects with two built-in browser programs: Inca for 3D and Pict for 2D drawing.

    jakobchristensen.com/students-on-the-loose

  • Choir · Critique Orchestrator

    A tool for getting feedback on a concept from many sides, using an AI like Claude or ChatGPT. It writes the prompts, and each side is played by a simulated persona. Many parts work together behind the scenes, so the feedback you get is varied and detailed rather than one generic answer.

    choirtool.com

  • Niagara Card Lab

    A teaching tool made for Realtime Art & Visual Effects students at the Salzburg University of Applied Sciences (FH Salzburg), for a workshop on visual effects in Unreal Engine. It shows each Niagara module as a card, so the modules are easier to understand. A particle emitter in the browser lets you try them out, and an export script brings the setup into Unreal.

    jakobchristensen.com/niagara-workshop
