  • Jakob's Agent Skills

    Agent skills I created from my own workflow, shaped by use: every project showed me something to fix. Some of them run through almost everything I do with AI. If one fits how you work, take it and adapt it.

    Installation: download a skill, drag it into your AI's chat and write "Install this skill."

    Results

    • /workaround

      MD Finds another route when the direct one is blocked

      AI agents sometimes keep running into the same wall instead of looking for a way around it. This skill finds another way to your goal when something outside your control blocks the direct one, like a failing tool or a missing feature.

      It checks that the new route really works and tells you what it cost. It stops at permission and security checks instead of getting around them, and asks before system-wide changes like a global install or before deleting something that can't be restored.

      Start it with /workaround.

    • /blindfold

      ZIP Blind test: is the changed prompt really better?

      It is easy to believe a rewrite helped and hard to know. This skill runs a blind, counted test of whether a changed prompt, skill or agent does better than the old version and than none at all, or a calibrated audit of many texts by blind readers. The audit first checks the readers on known bad and good examples before a clean result is trusted.

      It fixes the right answers before any answer is read, hides which version wrote what, lets two judges score each answer in a different order and counts hits, misses, extras and false alarms. It tells you the setup, its weaknesses and the cost first and starts nothing before your OK.

      Start it with /blindfold.

    • /media-review

      ZIP Checks generated images, audio and video against your brief

      A prompt that worked says nothing about the result it produced. This skill checks images, audio and video that another model made against your requirements, measures the actual files, and tells you up front which parts only your eyes or ears can judge.

      Before a paid or slow generation run, it tells you the cost and what it cannot check, and waits for your yes. It starts with one small sample, shows you only the assets that passed, and names every failed one with the requirement it missed.

      Start it with /media-review, or ask whether a generated result is good enough. The image check runs a bundled Python script, the audio and video checks use whatever tools your machine has. Unzip it into your skills folder so media-review/SKILL.md ends up there.

    • /reroll

      MD Asks again in a new chat that never saw the first answer

      When an answer misses, asking again in the same chat starts from the model's own first attempt, so the new answer is shaped by it (it avoids it or circles around it). This skill hands your own request, word for word, to a brand-new session that has never seen the rejected answer, so you get an independent second attempt.

      It never summarizes or comments on the earlier answer. /reroll 2 or /reroll 3 starts that many parallel attempts, /reroll different tells the new session that an earlier answer was rejected (never what it said) and asks it to avoid the most obvious choices, and a model name such as /reroll sonnet picks the model. Any other text is added as a note.

      The separate session needs the Claude Code desktop app. Everywhere else it copies the prompt to your clipboard or prints it, and you paste it into a new chat yourself. Start it with /reroll, or say "reroll" or "ask a fresh chat".

    Cost

    • /cheap-agents

      MD Picks the cheapest model that does the job

      Helper agents cost extra tokens, and a helper may report something that is not true, so someone has to check it. This skill makes the agent decide whether a helper is worth it at all, and pick the cheapest model that does the job.

      If you did not ask for helpers, or it wants more than two, it first tells you how many, which model each one uses and a rough cost estimate, and waits for your yes. Each helper gets a written brief with its goal and its limits. When a helper reports back, the agent looks at the real files instead of just trusting the report.

      Start it with /cheap-agents, or ask your agent to use helpers. Small tasks it does itself, without helpers.

    • /fresh

      MD Hands your work over to a fresh session

      The longer a session runs, the more context piles up, and the slower, costlier and less precise the agent gets. This skill carries your work over to a fresh agent session at a natural break, like a long conversation, a long pause, a new topic or a finished task.

      It writes a summary of the work so far, names the recommended model and effort for the next session and offers to start it. The summary builds on Matt Pocock's fantastic /handoff, which writes one when you call it.

      /fresh also decides when it is time to create a handoff, and an optional Claude Code hook nudges it when the context gets large or after a long pause. After its first run in Claude Code, /fresh asks once whether to set the hook up; it changes nothing without your yes and keeps a backup of your settings.

      It also works the other way round: when a session starts from a handoff file, or you say to continue after a crash or stop, it first checks the real state (git, branch, background jobs), lists what differs from the handoff, then carries on and never kills a process to get around a block.

      Runs on its own when the hook is set up (Claude Code), or start it with /fresh.

    Git

    • /strays

      MD Finds git commits that never reached the remote

      Work you committed but never pushed is easy to forget. This skill finds git commits that never reached the remote, on a side branch, the wrong branch or in a worktree, and shows them in one table before anything is sent.

      It pushes only after your OK, with safe pushes only: no force, each branch by its exact commit, and the default branch only as a fast-forward. A diverged branch is reported and left to you, and uncommitted changes are never touched.

      Start it with /strays, or add "push everything" to skip the question. It only works with committed work.

    • /tidy-worktree

      MD Removes worktrees whose work has landed

      Old worktrees and branches pile up in a repository, and it is hard to tell which ones are safe to delete. This skill removes only the git worktrees and branches whose work has landed in the default branch and whose worktree is clean, and keeps everything else.

      It never fetches or pushes, never forces a removal, deletes branches only with the safe git branch -d, and leaves the main checkout, locked worktrees, the one you are in and detached HEADs alone. It only reports stale worktree entries and prunes them after your OK. It needs git 2.31 or newer.

      Start it with /tidy-worktree, or ask which worktrees would be removed.

    • /lanes

      ZIP Gives every agent session its own worktree

      When several agent sessions change one git repository at the same time, they overwrite each other's work and break the main branch. This skill gives every AI agent session in a git repository its own worktree and branch, keeps the main checkout clean as the place where finished work lands, and stages only named files.

      A bundled script integrates one branch at a time: it merges into a temporary worktree, runs the full check there and moves the main branch with a fast-forward only when the check is green. It waits for uncommitted work of other sessions instead of touching it. The script runs on Windows PowerShell and needs git, an optional guard hook needs Claude Code and Node.js.

      Unzip it into your skill folder, so lanes/SKILL.md ends up there. Start it with /lanes. In a project without the integration script it asks once, after its first manual integration, whether to set it up, and changes nothing without your yes.

    Housekeeping

    • /freeup

      ZIP Frees disk space, deletes only what you approve

      Windows slowly fills the system drive with caches and temp files nobody needs. This skill measures the junk on C: (temp folders, npm cache, graphics shader caches, crash dumps) and can also find cache-like folders on your other drives, shows you a size table and deletes the rows you approve with one yes.

      It deletes only files that programs rebuild on their own and that are older than the age limit shown in the table. Files in use stay, and nothing is retried or forced. Downloads, worktrees and logs are only shown, never touched. Folders on other drives are cleaned only if you accept them.

      Windows only, it runs a PowerShell script and needs nothing else to install. Start it with /freeup, or ask for space on C. Unzip it into your skills folder so freeup/SKILL.md ends up there.

    • /tidy-sessions

      MD Archives finished sessions, keeps unfinished ones

      Finished sessions pile up in the sidebar. This skill archives your finished sessions in the Claude desktop app and keeps every session with unfinished work, after it has read how each one ended and checked in git that its branch has landed and its worktree is clean.

      It never deletes a session and never archives the one it runs in. Archived sessions can be restored, but their worktree is not a backup, so it keeps every session with uncommitted work and lists what needs your attention.

      Only for the Claude desktop app (Code tab), because it uses the app's session tools. Ask it to tidy your sessions, or which ones would be archived.

    • /fingerprints

      ZIP Checks a folder for private traces before you share it

      A folder you share can carry your name, a home folder path or a key without you noticing. This skill checks a folder (a skill, a repository, a project or a site) before you share it and lists what to fix: private words you give it, absolute and home paths, email addresses, keys and tokens. For a skill folder it also checks the header and terms that belong to one tool.

      It runs a small Python script (Python 3, nothing else to install), reads the working files but not the git history, shows a found key only masked, and changes nothing unless you ask for fixes. It is not a full secret scanner and does not judge whether the content is good.

      Start it with /fingerprints, or ask whether a folder is safe to share. Unzip it into your skills folder so fingerprints/SKILL.md ends up there.

  • Niagara Card Lab

    jakobchristensen.com/niagara-workshop

    A teaching tool made for Realtime Art & Visual Effects students at the Salzburg University of Applied Sciences (FH Salzburg), for a workshop on visual effects in Unreal Engine. It shows each Niagara module as a card, so the modules are easier to understand. A particle emitter in the browser lets you try them out, and an export script brings the setup into Unreal.

  • Choir · Critique Orchestrator

    choirtool.com

    A tool for getting feedback on a concept from many sides, using an AI like Claude or ChatGPT. It writes the prompts, and each side is played by a simulated persona. Many parts work together behind the scenes, so the feedback you get is varied and detailed rather than one generic answer.

  • Students on the Loose (incl. Inca 3D & Pict 2D)

    jakobchristensen.com/students-on-the-loose

    Small pixel students walk across the page and react to objects you place there. You create and place the objects with two built-in browser programs: Inca for 3D and Pict for 2D drawing.

  • Student Handbook

    studentbenefits.page

    A guide for animation students at the Salzburg University of Applied Sciences (FH Salzburg) in Austria. It explains the equipment and software the school gives students access to. It also lists student events, film festivals, job offers and discounts.
