Puts a check mark on finished sessions in Claude Code Desktop

In a long session list you cannot tell which chats are done. This skill puts a check mark at the very start of a finished session's title, marks the session completed and ends the chat with a short bullet report and the word "Done."

It seals only after it has checked that nothing is open: deliverables shown, no question waiting, no job still running, git clean. It never archives or deletes a session.

Renaming needs the Claude desktop app (Code tab); elsewhere it writes only the report. Ask it to seal a finished session, or let other skills call it.

When the agent uses it

Seals a finished chat session so it is easy to spot in the session list - puts a check mark at the very start of the session title, marks the session completed, and ends the last message with a short bullet report and the word "Done." as its own paragraph. Use when the user asks to mark a session as finished, done, sealed or ticked off, or says wrap up, finish or sign off for the session, or when another skill says to seal the session; the skill still checks every condition below itself before it seals. Not for a session that still has open work, pending operations, unresolved failures or open questions, not for archiving sessions (that is attic) or deleting them, and not for deciding whether the work is finished (that is a separate check).

Install

Download the skill, drag it into your AI's chat and write "Install this skill."
