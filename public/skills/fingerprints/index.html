/fingerprints

Checks a folder for names, paths and keys before you share it

A folder you share can carry your name, a home folder path or a key without you noticing. This skill checks a skill, repository, project or site before you share it and lists what to fix: private words you give it, absolute and home paths, email addresses, keys and tokens.

It changes nothing unless you ask for fixes. It does not read the git history and is not a full secret scanner.

It needs Python 3. Start it with /fingerprints, or ask whether a folder is safe to share. Unzip it into your skills folder.

Download ZIP Read SKILL.md

When the agent uses it

Checks a folder before it is shared or published, most often a skill folder. Runs a bundled script that finds private words, absolute and home paths, email addresses, keys and tokens, and for a skill folder also wrong or missing SKILL.md fields and terms that belong to one tool, then reports what to fix. Use when the user is about to share, publish, zip or push a skill, repository, project or site folder, or asks whether it is safe to release. Not a replacement for a dedicated secret scanner, and not for judging whether the content is any good.

Install

Download the skill, drag it into your AI's chat and write "Install this skill."
