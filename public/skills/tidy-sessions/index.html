/tidy-sessions

Archives finished sessions in Claude Code Desktop, keeps the rest

Finished sessions pile up in the sidebar. This skill archives your finished sessions in the Claude desktop app and keeps every session with unfinished work.

It reads how each session ended and checks in git that its branch has landed and its worktree is clean. It never deletes a session and lists what needs your attention.

Only for the Claude desktop app (Code tab). Ask it to tidy your sessions, or which ones would be archived.

Download SKILL.md Read SKILL.md

When the agent uses it

Archive every finished or superseded session in the Claude desktop app's session list so the sidebar stays short. Use only when the user asks to tidy up, clean up or archive their Claude Code sessions in the desktop app (not code, files or git), or asks which sessions would be archived or which are waiting for them. Not for deleting sessions and not for the running session. To remove landed git worktrees and branches without the desktop app, use the tidy-worktrees skill.

Install

Download the skill, drag it into your AI's chat and write "Install this skill."
