/reroll

Asks again in a new chat that never saw the first answer

Ask again in the same chat, and the new answer is shaped by the old one. This skill hands your request, word for word, to a new session that has never seen the rejected answer.

/reroll 2 or /reroll 3 starts that many attempts in parallel, /reroll different asks for less obvious choices, and a model name such as /reroll sonnet picks the model.

Outside the Claude Code desktop app, you paste the prompt into a new chat yourself. Start it with /reroll, or say "reroll" or "ask a fresh chat".

Download SKILL.md Read SKILL.md

When the agent uses it

Rerolls the last answer blind by handing the user's own request word for word to a brand-new session that has never seen the rejected answer. Use with /reroll, or when the user says "reroll", "ask a fresh chat" or "try again without seeing your answer", or wants an unanchored second attempt at an answer they disliked (ideas, brainstorm, tips, a plan). Not for fixing a factual error in the answer (just fix it) and not for continuing work.

Install

Download the skill, drag it into your AI's chat and write "Install this skill."
