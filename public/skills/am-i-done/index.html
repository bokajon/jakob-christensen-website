/am-i-done

Checks whether the whole task is finished before you close the chat

When you close a chat, it is hard to know whether anything is left behind. This skill goes through everything the chat set in motion and lists what is still open: requests you made that were never done, sessions that still run or wait for you, and work that is not yet committed, merged or deployed.

It answers with a colour: green means you can close the chat, orange means nothing open was found but not everything could be checked, red comes with the list of open points. It only reads and never fixes or archives anything.

Start it with /am-i-done, or ask "can I close this chat?". The other-session checks need the session tools of the Claude desktop app; elsewhere it checks the conversation, git and your notes files and says what it could not check. It has not yet been run against real multi-session setups.

When the agent uses it

Checks whether the whole task is finished before the user closes a chat - this conversation, every session it started, the session that started it, other parts of the same /fresh series, and the git and deploy state - and answers with a green "done, you can close this chat", an orange "nothing open found, but not everything checked" or a red "not yet" plus the list of open points. Use with /am-i-done, or when the user asks whether the whole task is finished or the chat can be closed ("am I done with this whole task?", "can I close this chat?", "anything left?", "bin ich fertig?", "kann ich den Chat schließen?"). Not for a single build, test, commit or deploy ("did the build finish?"), not for a project-wide backlog ("what is still open in this project?"), not for action requests ("wrap this up", "commit and push"), not for archiving sessions (that is tidy-sessions), not for handing unfinished work to a new session (that is fresh), and it does not fix the open points it finds.

Install

Download the skill, drag it into your AI's chat and write "Install this skill."
