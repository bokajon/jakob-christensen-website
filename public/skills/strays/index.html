/strays

Finds commits you never pushed, and pushes them after your OK

Work you committed but never pushed is easy to forget. This skill finds git commits that never reached the remote, on a side branch, the wrong branch or in a worktree, and shows them in one table before anything is sent.

It pushes only after your OK and never by force. Diverged branches and uncommitted changes are left to you.

Start it with /strays, or add "push everything" to skip the question.

Download SKILL.md Read SKILL.md

When the agent uses it

Find stray local git work (branches and commits not on the remote yet) and push it with safe pushes only - no force, each branch by its exact commit, the default branch only fast-forwarded. Shows an overview first and pushes nothing before the user agrees. Use when the user asks to push their already committed work, to find unpushed commits or branches, or to check what is only local. Not for staging or committing changes, opening pull requests, merging or resolving diverged branches.

Install

Download the skill, drag it into your AI's chat and write "Install this skill."
