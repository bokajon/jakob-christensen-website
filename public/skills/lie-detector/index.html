/lie-detector

Makes your agent measure claims like faster, smaller or unused

Agents like to report that something is now faster, smaller or unused after one run, or after none. This skill has the agent measure every claim about speed, size, share, ranking or unused code in your software, and mark what it could not measure as "not checked".

For timings it checks the machine's load, warms up, repeats the run, and gives the median and the spread. A result counts as reproduced only after a second, separate series, and a difference smaller than the noise counts as no difference. Values come from the running app and never from a test fixture. Before it calls code unused, it searches code, tests, config, scripts and docs for it.

It needs a shell. It changes no system settings, does not repeat commands that deploy, send or call a paid or shared service, and does not review other people's reports. Careful measuring takes longer than guessing.

Start it with /lie-detector, or ask whether something really got faster, smaller or is unused.

When the agent uses it

Measures performance, timing, size, share, ranking and unused-code claims about software itself, with a warm-up, repeated runs, median and spread, a machine-load check and runtime values taken from the running app and not from test fixtures. Use when about to report or confirm that something is faster, slower, smaller, under a time limit, the largest, a given share of a folder or bundle, a frame rate, a load time, or unused or dead code. For a single fixed fact that can be read directly (a line count, one file's size) one command is enough and no repetition applies. It does not review other people's claims or reports.

Install

Download the skill, drag it into your AI's chat and write "Install this skill."
