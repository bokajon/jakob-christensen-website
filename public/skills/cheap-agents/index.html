/cheap-agents

Decides if a helper agent is worth it, and which model is good enough

Helper agents cost extra tokens, and someone has to check what they report. This skill makes the agent decide whether a helper is worth it at all, and pick the cheapest model that does the job well.

If you did not ask for helpers, or it wants more than two, it first names the number, the models and a rough cost, and waits for your yes. It checks every report against the real files.

Start it with /cheap-agents, or ask your agent to use helpers.

Download SKILL.md Read SKILL.md

When the agent uses it

Decides whether to hand part of a task to another agent or session, picks the cheapest model and effort that does that part well, writes a brief the helper can build from, and checks what comes back before relying on it. Use when a task has independent parts, a long search or read, work that should run in parallel or in the background, or when the user asks for agents, sub-sessions or lower token or model cost. Not for small tasks that can be finished in a few tool calls.

Install

Download the skill, drag it into your AI's chat and write "Install this skill."
