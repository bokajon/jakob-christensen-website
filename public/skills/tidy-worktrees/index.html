/tidy-worktrees

Removes worktrees and branches that have landed, keeps the rest

Old worktrees and branches pile up, and it is hard to tell which ones are safe to delete. This skill removes only the git worktrees and branches whose work has landed in the default branch and whose worktree is clean, and keeps everything else.

It never pushes or forces a removal, and leaves locked worktrees and the one you are in alone.

Start it with /tidy-worktrees, or ask which worktrees would be removed. It needs git 2.31 or newer.

Download SKILL.md Read SKILL.md

When the agent uses it

Remove local git worktrees and branches whose work has safely landed in the default branch and whose worktree is clean, and keep everything else. Use when the user asks to tidy up, clean up or remove old worktrees and branches in a git repository, or asks which ones would be removed. Needs only git and runs in any tool. Not for pushing unpushed work, not for the single worktree a session just finished with, not for remote branches and not for archiving sessions in an app.

Install

Download the skill, drag it into your AI's chat and write "Install this skill."
