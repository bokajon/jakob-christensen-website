/lanes

Keeps agent sessions from overwriting each other's work in one repo

Agent sessions that change one git repository at the same time overwrite each other's work, causing lost changes and broken builds. This skill gives every agent session its own worktree and branch, keeps the main checkout clean and lands finished work there one branch at a time.

A bundled script moves the main branch only when the full check on the merged result is green. Uncommitted work of other sessions stays untouched.

The script needs Windows PowerShell and git, and is set up only after your yes. Start it with /lanes. Unzip it into your skills folder.

Download ZIP Read SKILL.md

When the agent uses it

How several agent sessions work on one git repository at the same time without breaking each other. One worktree and branch per session, a main checkout that stays clean and is only the integration target, named-file staging, a check before every commit, and a bundled script that integrates a branch one at a time (merge and full check in a temporary worktree, fast-forward only). Use when starting work in a repository other sessions also use, when finishing a branch that must reach the default branch, or when the user asks to set up parallel agent sessions in a project. Not for projects that integrate only through hosted pull requests.

Install

Download the skill, drag it into your AI's chat and write "Install this skill."
