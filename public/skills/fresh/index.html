/fresh

Spots when a session gets too long and hands the work to a fresh one

The longer a session runs, the more context piles up, and the slower, costlier and less precise the agent gets. This skill carries your work over to a fresh agent session at a natural break, like a long conversation, a long pause, a new topic or a finished task.

It writes a summary of the work so far, recommends a model and effort for the next session and offers to start it. The summary builds on Matt Pocock's fantastic /handoff skill, which writes one when you call it.

It also works the other way round. When you continue from a handoff file, or after a crash or stop, it first checks the real state and lists what differs.

Start it with /fresh. It also decides when it is time for a handoff. In Claude Code, an optional hook reminds it, set up only after your yes.

Download SKILL.md Read SKILL.md

When the agent uses it

Ends a long or finished session cleanly - writes a handoff file without asking, names the model and effort for the next session, numbers the sessions of one task (part 1, part 2, ...) so the newest is always clear, and offers a fresh one. Also resumes work from a handoff file or after a crash or stop: it checks the real state first, names every difference from the handoff, then continues. Use at a natural break when the context is large (about 150k tokens), after a pause of over an hour on a context of 60k tokens or more, when the user moves to a different task with unfinished work behind, after image-heavy work, or when a task is merged and other work follows; and, to resume, when a session starts from a handoff file or the user says to continue after a crash or stop. Not for sessions with nothing to carry over, and never before the current request is done.

Install

Download the skill, drag it into your AI's chat and write "Install this skill."
