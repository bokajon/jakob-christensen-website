Docs: Cache lifetime

Bricht / bleibt

Bricht

  • Modellwechsel (auch Skill mit model, opusplan)
  • Effort ändern (nicht auf 5.5-Modellen und Fable 5.1+ mit Abo/API-Key)
  • Fast mode umschalten
  • /compact, Auto-Compaction
  • MCP-Server dazu, wenn Tools nicht deferred
  • viele Bilder
  • Update von Claude Code

Bleibt

  • Dateien bearbeiten
  • CLAUDE.md ändern (wirkt erst nach /clear, /compact, Neustart)
  • Permission mode, Output style
  • Skills, Befehle, Plugin-Skills/Hooks
  • /rewind, /recap
  • Subagent starten (eigener Cache); Fork liest den Cache der Hauptsession

Docs: Actions that invalidate the cache

Faustregeln

  • Modell und Effort am Anfang der Session wählen.
  • /compact an einer Pause während der Arbeit, nicht nach langer Abwesenheit.
  • Holzweg verwerfen: /rewind statt /compact.
  • Neues Thema: /clear, kostet nichts.
  • Cache gleicher Ordner wird zwischen parallelen Sessions geteilt, verschiedene Ordner (Worktrees) nicht.
