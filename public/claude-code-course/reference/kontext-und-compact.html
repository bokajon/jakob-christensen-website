Kontext und /compact

Was wann in den Kontext lädt und was ein Compact übrig lässt.

Wann was lädt

WannWas
Beim StartSystemanweisung, CLAUDE.md (global, Projekt, Elternordner), Regeln ohne paths:, Auto-Memory (MEMORY.md), Skill-Beschreibungen, MCP-Tool-Namen, Umgebungsinfo
Bei BedarfSkill-Text (beim Aufruf), Regeln mit paths: und CLAUDE.md aus Unterordnern (beim Zugriff auf passende Dateien), Memory-Themendateien (Claude liest sie selbst), jede Datei, die Claude liest
Immer weiterTool-Ergebnisse, Hook-Ausgaben, Antworten

Docs: Explore the context window, Docs: Memory

Grenzen

WasGrenze
MEMORY.md beim Starterste 200 Zeilen oder 25 KB
CLAUDE.mdganze Datei bis 4 MiB, Ziel unter 200 Zeilen. Imports sparen keinen Kontext
Skill-Text nach Compact5.000 Tokens je Skill, 25.000 gesamt
Dateien nach Compactbis zu 5, zuletzt geänderte zuerst, über 5.000 Tokens nur als Pfad
Auto-Compact, 1M-Modelleetwa 967.000 Tokens, oder deine Grenze (autoCompactWindow, /autocompact, mindestens 100K)

Docs: Set the auto-compact window

Nach /compact

Kommt zurück

  • Projekt-CLAUDE.md, Regeln ohne paths:
  • Auto-Memory
  • Skill-Beschreibungen
  • Plan aus dem Plan-Mode
  • bis zu 5 Dateien, Skill-Texte (gekappt)
  • SessionStart-Hooks mit Quelle compact
  • Hintergrund-Befehle laufen weiter

Wird zusammengefasst

  • der Gesprächsverlauf
  • Regeln mit paths: (laden bei passender Datei neu)
  • CLAUDE.md aus Unterordnern (laden bei Bedarf neu)
  • frühere Hook-Ausgaben
  • Dateien jenseits der fünf

Docs: What survives compaction

Befehle

BefehlWirkung
/context, /context allLive-Aufteilung nach Kategorie; all zeigt unter Memory files, was beim Start geladen wurde
/memoryCLAUDE.md und Auto-Memory öffnen und bearbeiten
/compact focus on ...Zusammenfassung behält, was du nennst
/rewind, Summarize from / up to herenur einen Teil des Verlaufs zusammenfassen
/autocompact 500kFüllgrenze für das aktuelle Modell setzen, auto setzt zurück
/clearneues Thema, leert den Kontext

Faustregeln

  • Regel, die immer gelten muss: Projekt-Root-CLAUDE.md, nicht paths: und nicht Unterordner.
  • Wichtigstes in einem Skill an den Anfang von SKILL.md.
  • Große Lesearbeit an einen Subagenten: dein Fenster bleibt klein, seine Tokens kosten trotzdem.
  • Fehlt eine CLAUDE.md in /context all unter Memory files, sieht Claude sie nicht.
