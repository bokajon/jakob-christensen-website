Entscheidung

  • Wenig Gespräch nötig, viel Lesen/Suchen: Subagent auf Haiku/Sonnet.
  • Viel Gespräch nötig, Modell darf gleich bleiben: Fork.
  • Eigene Sache mit eigenem Ergebnis, länger, steuerbar: neue Session.
  • Kurze Rückfrage zu Gesprächsinhalt: /btw (keine Werkzeuge, nicht im Verlauf).

Fallen

  • Viele Subagenten mit langen Berichten füllen trotzdem deinen Kontext; jeder verbraucht eigene Usage.
  • Fork aus einer Opus-Session = Opus-Arbeit.
  • Subagent mit dünnem Auftrag sucht sich alles neu zusammen.
