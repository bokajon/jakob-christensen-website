# Card text for /reroll (released 2026-11-24, approved by Jakob, shortened on his request the same day)

Summary line: Asks again in a new chat that never saw the first answer

Paragraph 1: Ask again in the same chat, and the new answer is shaped by the old one. **This skill hands your request, word for word, to a new session that has never seen the rejected answer.**

Paragraph 2: `/reroll 2` or `/reroll 3` starts that many attempts in parallel, `/reroll different` asks for less obvious choices, and a model name such as `/reroll sonnet` picks the model.

Paragraph 3: Outside the Claude Code desktop app, you paste the prompt into a new chat yourself. Start it with `/reroll`, or say "reroll" or "ask a fresh chat".
